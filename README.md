# Fracxtl
Fracxtl is a browser-based steganography tool that encrypts text messages with AES-256-GCM and hides the ciphertext inside a Mandelbrot fractal PNG image, with no pixel modification and no server required.

## Features

1. Encrypt messages with AES-256-GCM and embed them in a PNG's tEXt chunk
2. PBKDF2 (600k iterations) → HKDF key derivation for strong password hashing
3. HMAC-SHA256 authentication — wrong password fails instantly
4. Mandelbrot fractal parameters seeded by a random per-encryption salt via HKDF — every encryption produces a unique image, even with the same password
5. Runs entirely in the browser, nothing leaves your machine

## Usage

1. Download or clone the repository
2. Open `fractalCrypto.html` in your browser
3. Enter your message and a password
4. Click Encrypt — save the generated PNG
5. To decrypt, upload the PNG and enter the same password

## Notes

* Security depends entirely on password strength — use a long passphrase
* Not audited by a professional cryptographer, use accordingly
* Decryption tab works with PNGs generated by Fracxtl only
* The payload is not hidden from inspection — metadata tools like `exiftool` will show the tEXt chunk immediately. It's encrypted, not invisible. Re-saving or re-compressing the PNG through another program or platform (e.g. re-encoding, some chat apps, some image hosts) can strip the chunk entirely, destroying the payload
